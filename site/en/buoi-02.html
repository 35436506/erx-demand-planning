Understanding and cleaning demand data

From sales data to demand data you can trust

Stage 1 · FoundationsClass date: ILO2

By the end of this session you will be able to

  1. Distinguish orders – shipments – invoices – sell-out – demand and choose the right source
  2. Read a time series through four components: level, trend, seasonality, noise
  3. Use the mean, median, standard deviation, CV and IQR to detect anomalies
  4. Classify anomalies: data error or real event — and treat each correctly
  5. Restore demand during stock-outs, fix unit errors, join old–new codes, interpolate gaps
  6. Keep an adjustment log: never delete the raw numbers; every change has a reason and evidence

Learning outcomes: ILO2 (prepare demand data, restore unconstrained demand, with an audit log)

Company corner

What does data look like in a real company? — Who owns the numbers, when they are frozen, who may change them — and a 'sold 0 for 3 months' case.

Case · An SKU sold 0 for 3 months
  • An automated report flags three items that all 'sold 0' in the last three months:
  • Item A: vegetarian noodles — stock still on hand, ERP status 'active'
  • Item B: fish sauce 1L PET bottle — stock = 0, and a new code with a similar name appeared three months ago
  • Item C: OEM seasoning powder — history shows orders only every 3–4 months, 4–12 batches each
  • The manager asks: 'Should we set the forecast for these three items to 0?'
Discussion questions
  1. For each item, diagnose: stock-out, code change, discontinued or genuinely intermittent demand?
  2. Which data would you check, and whom would you ask, for each item?
  3. For which item is a zero forecast right? What happens if you apply it to item C by mistake?
  4. Write a 'When… if… then… unless…' rule for this situation.

Exit ticket · self-check

Answer in the last 2–3 minutes of the session. The instructor goes through the answers in class — record how many you got right.

  1. Supermarket A sends a PO for 7,700 cases of green tea; the warehouse can only ship 5,450 because bottles ran short → what was demand that month?
  2. A distributor receives 56,000 cases of noodles in September but sells only 49,300 to stores → which number is accounting's 'sales' and which is closer to demand?
  3. In March a distributor returns 1,450 cases of Tết biscuits → is March demand negative?
  4. The ERP report shows N03 selling 136,656 'cases' in August while other months are ~6,000 → what might have happened?

Key points to remember
  • Choose the source closest to the buyer — and state clearly which source you used
  • A statistical flag is a question; only business investigation gives the answer
  • Three layers of numbers + a log: never delete, only add columns, every change has evidence
